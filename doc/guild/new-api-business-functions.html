整体定位

new-api 是一个多 AI 厂商统一接入网关：对外暴露 OpenAI 全协议 + Anthropic 协议兼容接口，对内聚合 41 套上游通道（含 Sora/可灵/Vidu/Claude/Gemini/Bedrock/DeepSeek/智谱等）。产品面向三类使用者提供差异化能力。

一、对 AI 调用方 核心产品

开发者用 SDK/HTTP 调用的能力，对应 OpenAI/Anthropic 协议的全部覆盖。

  1. 统一协议接入OpenAI 全协议兼容：Chat / Completions / Edits / Embeddings / Images / Audio / Files / Fine-tunes / Moderations / Assistants / Batches / Realtime / Responses 共 13 类端点，零改造替换 OpenAI 客户端。同时支持 Anthropic Messages 协议。
  2. 多模态生成文生图 / 图生图 / 图像变体 / 图像编辑（inpainting）/ 视觉理解（vision）/ TTS / STT / 翻译 / InsightFace 换脸。
  3. 异步视频生成text2video / image2video 异步任务，覆盖 11 个视频/音频模型：Sora、可灵、Vidu、豆包、海螺、Suno、Gemini 异步、Vertex 异步等。
  4. 重排序与搜索Rerank（Jina 等多家）+ Alpha 搜索引擎适配，作为额外非生成型 AI 能力。
  5. 智能路由多 Key 池自动选 · 渠道权重 · 按用户/模型动态映射 · 失败自动切换 · 上下文压缩 · 流式响应 SSE。
  6. Files 与 Fine-tunesOpenAI Files API 兼容 · 文件上传/下载/检索/内容回放 · 微调任务创建/查询/取消/事件流。
  7. 实时语音Realtime WebSocket 协议适配，支持低延迟双向语音对话。

二、对终端用户 付费 C 端

使用平台的开发者或团队账号使用方，对应账户、付费、激励流程。

  1. 账户体系邮箱注册 / 登录 / 注销 · 密码重置 · 邮箱验证 · 2FA（TOTP）· Passkey（WebAuthn 抗钓鱼生物凭据）· Session 会话管理。
  2. 第三方登录Linux DO / Google / GitHub / 微信 / Telegram / 自定义 OIDC 共 6+ 种 OAuth 渠道，含邮箱绑定流程。
  3. 多档充值Top-up 多档套餐 · 支付宝 epay · Stripe · Creem · Waffo · Waffo Pancake 共 6 种支付通道，全部 Webhook 自动回调与签名校验。
  4. 订阅套餐Plans 订阅 · 套餐生效 / 续费 / 退订 · Dashboard 实时余额 / 配额 / 用量。
  5. 每日签到Check-in 积分激励体系，提升留存。
  6. 邮件流程邮箱验证 + 密码重置 + Turnstile 人机验证，关键路径含 CriticalRateLimit 防滥用。

三、对运营管理员 后台管控

平台运营者 / 渠道管理者使用的后台能力，对应渠道、模型、用户、数据、设置。

  1. 渠道管理Channel 多 Key 池 · 分组优先级 · 上游模型同步 · 渠道健康检测 · 亲和性缓存 · 实例级缓存复用 · 渠道能力矩阵。
  2. 模型管理Model 清单 · 元数据 · 可见性分组 · 缺失模型自动补齐 · 同步预览 · 模型所属 vendor · model mapping。
  3. 用户管理用户列表 · 封禁 / 解封 · 额度调整 · 订阅管理 · 搜索 · 用户级 passkey 管理。
  4. 数据看板Dashboard 营收 · 用量 · 排行 · 账单 · 订阅概览 · 2FA 统计。
  5. 审计与合规操作日志审计 · 支付合规检查 · webhook 签名校验 · 支付回调可用性监控。
  6. 系统设置比例 / 模型 / 性能 / 控制台 / 操作 / 推理 / 系统 / 计费 共 9 套 setting，可热更新。

四、对部署运维 自托管

自部署或运维团队的工程能力，对应集群、可观测性、中间件、初始化。

  1. 多节点部署Master / Worker 选举 · 实例心跳 · 失效实例自动清理 · 节点亲和性缓存 · 集群内通信（pkg/ionet）。
  2. 可观测性Prometheus 指标埋点 · Pyroscope 持续剖析 · pprof 在线诊断 · 结构化日志 · 性能指标 TTFT / 时延 / 渠道延迟分布。
  3. 中间件栈多档限流（Critical / Global / EmailVerification）· CORS · Gzip 压缩 · Turnstile 反爬 · Body 大小限制 · DisableCache · Session 防泄漏。
  4. 首启引导Setup 自动初始化 · 数据库迁移 · 默认配置生成 · 首登 admin 引导。
  5. 单文件部署前端构建产物通过 embed.FS 打入 Go 二进制，一份二进制即完整服务，含 web/dist。

五、横向能力 全栈通用

贯穿全栈、与具体业务正交的能力。

  1. 权限分级Casbin RBAC 模型 · 服务端 service/authz 鉴权 · 用户 / 管理员 / 渠道级细粒度策略。
  2. 反滥用与风控多档 RateLimit + Turnstile + 邮箱验证 + 关键路径 CriticalRateLimit，构建多层防护。
  3. 国际化i18n 多语种支持 · i18n/locales 多语言资源 · 前端文案按 locale 切换。
  4. 缓存与限流基础common/limiter · pkg/cachex · 磁盘缓存 · 渠道亲和性缓存 · 热点 key 复用。

5 大核心场景串联

把上面五类的关键节点串起来，就是产品的 5 个主要用户场景。

  1. 用户注册到首次调用C 端注册（邮箱/OAuth/Passkey）→ 充值（Top-up 或订阅）→ 调用方（开发者）通过 OpenAI 协议接入 → 智能路由选渠道 → 上游 API 响应 → 按 token 自动扣费。
  2. 管理员接入新 AI 通道运营在后台添加 Channel → 配置 Key 与分组 → 路由系统自动识别并加入智能路由 → 调用方立即可用。
  3. 异步视频生成调用方发起 text2video 任务 → 异步路由到 Sora/可灵/Vidu 等通道 → 任务进入 taskcommon 异步框架 → 调用方轮询或回调获取结果 → 扣费与配额扣减。
  4. 运维诊断线上问题通过 Prometheus + Pyroscope + pprof 三件套定位调用延迟/错误率/代码热点 → 通过 Casbin 审计日志回溯操作 → 通过 channel_affinity_cache 排查实例缓存问题。
  5. 多节点横向扩展Worker 节点启动 → 注册到 Master → 实例心跳上报 → 用户请求 Master 转发或本地命中缓存 → 失效实例自动清理。

一眼可见的产品卖点

  • 协议兼容零成本：13 类 OpenAI 端点 + Anthropic Messages，老代码几乎不用改就能迁移
  • 41 + 11 = 52 个 AI 厂商：对话/补全 41 + 异步视频/音频 11，且每家独立目录可单点扩展
  • 智能路由与多 Key 池：渠道权重 / 失败切换 / 上下文压缩，可视化配置
  • 多种计费订阅模型：Top-up + 6 种支付通道 + 订阅 + Webhook 全自动
  • 现代身份认证：邮箱 + 2FA + Passkey（WebAuthn 抗钓鱼）+ 6 种 OAuth
  • 完整可观测性：Prometheus + Pyroscope + pprof + 结构化日志 + 性能指标
  • 多节点 Master/Worker：可横向扩展，集群内通信自带
  • 单文件部署：前端通过 embed.FS 打入二进制，Docker 镜像即可交付
