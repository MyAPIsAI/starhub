# P5 可观测性：让中转「看得见」

| 层 | 实现 |
|---|---|
| 请求级 | `metric.BeginRequest/EndRequest`（relay.go:84-139）：状态码、重试次数、成功/流式中断分类 |
| 尝试级 | `metric.BeginAttempt`：每次上游调用单独记录 TTFT（首字延迟）、上游 request-id——定位"哪个渠道慢" |
| 渠道级 | 响应耗时滚动统计（测活任务回写 `ResponseTime`）、成功率、余额监控 |
| 业务级 | logs 表全量记账（P0 已有）+ 管理端多维护索；量大后分表或 ClickHouse |
| 告警 | 渠道禁用/启用即时通知管理员（邮件/webhook），余额不足、错误率阈值告警 |

**TTFT 是中转站的生命线指标**（流式场景用户感知的就是首字时间），必须从 P5 的第一天就埋点。
