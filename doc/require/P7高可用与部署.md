# P6 高可用与部署：让中转「扛得住」

## 水平扩展

- 多实例部署，状态全部外置
- 渠道缓存同步靠 DB 轮询（`SyncChannelCache`）+ 跨实例事件（Redis pub/sub 通知渠道变更）
- 会话/token 缓存走 Redis

## 数据层

- 三库兼容（SQLite 单机 / MySQL / PG）用 GORM 抹平
- `model/main.go` 的迁移模式（ALTER ADD COLUMN only）

## 性能

- gopool 异步化所有旁路操作（缓存回写/日志/metric）
- 请求体零拷贝重放
- SSE 流式直 pipe 不落内存

## 交付

- Docker Compose 一键起、健康检查端点、配置外置（`.env`/选项表）

## 两条不可妥协的工程纪律

（来自本仓库的教训沉淀，写进了 AGENTS.md）

1. **计费安全不变量**：任何计费乘数必须有界、任何 float→int 必须走饱和换算、预扣和结算双向防负——回归测试挂在边界上（`common/quota_math_test.go` 风格）
2. **可选字段用指针 + omitempty**：客户端显式传 `0`/`false` 和没传必须区分，否则中转会悄悄改变上游行为
