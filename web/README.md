# Veyra（平台）交互演示

一把 Key（密钥）授权一个服务分组；客户端在每次请求中选择具体模型或 `veyra-auto`（智能路由标识）。平台演示接入、授权、费用与异常排查。

本项目是可连续操作的本地演示。地址使用示例域名，凭证、模型调用、价格和支付均为模拟；没有真实网关、付费模型或支付渠道。

## 启动

直接双击 **启动正式版.command**。它会从源文件重新构建并打开本地预览；地址以终端输出为准，关闭终端会停止服务。需要 Node.js（运行环境）20.19 以上版本；依赖已存在时无需重新安装。

开发与验证命令：

```sh
npm run dev -- --port 5196 --strictPort
npm test
npm run check:i18n
npm run build
# 保持上面的开发服务运行，在另一终端执行：
npm run test:browser

npm run test:browser:channels
```

浏览器验收使用本机 Chrome（浏览器）。不同端口属于不同存储来源，可通过 `VEYRA_URL` 环境变量指定其他开发地址。

## 三条操作路径

首页“体验 Demo（演示）”或右下角“演示场景与重置”可一键进入。选择或重置场景会恢复演示余额、密钥、订单、调用、价格和草稿，不影响真实账户。

1. **首次接入**：创建密钥 → 接入中心选择工具 → 复制配置 → 可选验证 → 零余额拦截 → 模拟充值 → 用原输入重试 → 查看调用及关联流水。新账户没有赠送余额。
2. **多用途密钥管理**：一把研发多模型密钥、一把内容用途受限密钥 → 同一密钥切换具体模型与智能模型 → 编辑额度和白名单 → 验证越权或额度失败 → 查看各密钥消费。
3. **运营改价**：以系统管理员演示身份进入工作台“系统设置” → “标准模型”创建模型和维护价格，或“服务分组”修改倍率及账号范围；“渠道管理”维护资源实例映射和投放 → 查看影响 → 发布 → 提交模拟用量 → 查看新旧调用与流水。图片按张、视频按秒、表达式与分时时段均可试算、记账和重置。

## 本轮改动

- 公共导航移除“服务优势”，保留首页介绍。密钥列表按名称、分组、状态、额度、操作对齐；手机改为卡片，授权与地址限制移入详情，启停、重置和删除集中在更多菜单。
- 密钥额度与预警统一按真实周期消费计算，修复旧演示百分比；不限额不显示进度。查看/复制保留密码验证，到期隐藏，直接复制不展开明文。见 [公共导航与密钥列表整理](docs/24-公共导航与密钥列表整理.md) 及 [本轮验收](docs/verification-2026-09-28-key-list/验收说明.md)。
- 模型广场支持整卡/整行查看详情，复制与接入独立，文字仍可选择；保留名称、复制、能力/上下文和主要价格：词元模型只对照输入/输出；智能路由和复杂计价显示计费方式。缓存、来源、分组和估算条件集中到详情。公开最低价仅取有可用资源的通用分组，实际按密钥分组计费。
- 厂商官方参考独立维护来源、日期及适用条件；修改参考价不改平台基准或历史账单。未核实模型不补造官价，退役模型的参考明确标注为历史。

- 模型广场按厂商标签浏览，智能路由与媒体计费样例归入 Veyra（平台）；新增卡片/列表切换，搜索、分类、视图随刷新和详情返回恢复。服务分组退出分类，保留当前价格口径说明与详情比价。

- 账号中心包含固定用户标识、账号资料、登录与安全、模拟设备和最近安全操作。可真实修改演示密码、绑定邮箱、换绑手机号；登录和密钥解锁同步使用新凭据，账号标识及既有账本/权限不变。
- 当前版本统一为普通账号：默认演示、历史和新注册账号共用账号资料页；移除企业名称编辑及企业工作空间入口。平台管理员继续按角色显示系统设置，团队、成员和企业组织管理留待后续版本评估。
- 登录、注册和找回密码均在主页遮罩弹窗内；注册填写用户名、手机号、验证码、密码和确认密码，用户名或手机号可配合密码登录，支持手机号模拟验证码登录和密码重置。协议保持单一确认。注册仍为零余额普通用户，工作台展示用户名和手机号。
- 调用明细补齐独立日期选择、紧凑搜索、状态联合筛选和完整分页；服务质量改为核算单元列表进入独立详情，返回保留上下文，详情导出仅包含该单元。
- 渠道管理采用左侧目录、右侧资源工作区，支持按渠道与按标准模型两种视角；筛选、分页、刷新恢复和窄屏卡片均可连续操作。同步与导入收进独立入口。
- 标准模型可创建、编辑、停用和删除；渠道实例从本地资源快照同步，显式映射后可投放多个分组。
- 分组完整增删改查，支持通用/指定账号的定制组；可用模型从实例投放推导，不再维护另一套模型开关。
- 条件单位价支持分辨率、质量和音频；语言模型分时可独立设置输入、输出、缓存价格。
- 资源候选、模拟调用与快照同源，历史账单保留原资源与费率；动态分组刷新后不会丢失。

- 创建密钥的分组预览全宽、内部滚动、默认额度不重置；高级配置可收起，模型与网络地址白名单使用胶囊开关。
- 系统设置合并在工作台，管理员可见“标准模型”“渠道管理”和“服务分组”；原后台地址重定向，未新增独立后台。演示身份可在右下角切换。
- 基准来源、计价规则、分组倍率分开；支持词元、次数、张数、秒数、安全算术表达式及分时系数，结算保存规则和用量快照。

- 移除密钥模式二选一；授权、模型选择和路由分离，旧权限保守保留。
- 统一具体模型与智能模型目录，按当前服务分组展示对客价格。
- 新增工具接入中心，按目标协议筛选；配置复制与模拟验证分开。
- 使用同一请求对象驱动页面、模拟调用和代码导出，支持引号、换行与工具链约束。
- 请求、用量、费率快照、余额、订单与资金流水联动；失败不扣款并保留输入。
- 支持密钥权限和额度编辑、刷新恢复、三场景重置及窄屏操作。
